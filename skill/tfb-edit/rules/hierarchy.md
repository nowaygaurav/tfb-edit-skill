# hierarchy.md: visual hierarchy decision brain (DRAFT v2.1, not locked yet)

Status: the TFB style was finalised 2026-11-12 (Gaurav: "the style is decent for me"). Sources: (PLOS Biology 2025 V1 saliency paper + PLOS ONE 2024 sound-off subtitle eye-tracking study). The steps are Claude's translation of the papers into editing rules, not tested on reels.

Run on every frame. History: 2026-11-12 captions-next-to-the-focal-point (jumping position) replaced by one fixed home per case.

Run on every frame:
1. **Mute test:** does the frame say the line with no sound? If not, add what it needs in this order: **video clip first → photo if no video exists → word only if neither works** (his rule 2026-11-12).
2. One thing they must see (number, face, word). None → simplify or cut.
3. It is the odd one out by a lot: one feature pushed hard (3× size, only colour, only mover). 90°, not 15°.
4. **Captions have one fixed home per case** (his rule 2026-11-12, Helvetica Neue Bold, centred, no pill). The caption never jumps around:
   - **Host full screen:** just under the mouth/chin (until real avatar renders arrive, use the host band at y ≈ 1070).
   - **B-roll full screen:** lower middle, top ≈ y 1070, centred. **No other text on screen at all.**
   - **Infographic / motion graphic:** one band directly under the graphic, top ≈ y 1060 so the caption ends above y 1150 (wide captions would hit the x>850 corner), centred. The graphic lives in y 330–1030 and never enters the band.
5. **Text only when required.** B-roll, or motion graphics over B-roll = captions only. Infographic text must be **complementary** to the caption: it adds what the voice doesn't say (e.g. "21 years" under a bar while he says the rupee amount). **The same word or number never appears twice on screen at once**; if it would, the infographic drops it.
6. **Fewest words:** only the terms a viewer needs to get it. 2–4 word caption chunks, held long enough to read on mute.
7. Nothing else pops (logo, source, texture, second colour) → remove or match. See minimalism.md.
8. Emotion survives with no voice: the face (video first) or one key word carries it.
9. Glance test: squint, grayscale, mute. Fail → back to 1.

## The three channels (his rule 2026-11-12, every edit, b-roll too)
What the viewer **hears** (voice), **reads** (caption) and **sees** (visual) must complement each other, never repeat each other.
- **The visual must explain the line on its own.** Cover the caption: if the motion doesn't show what he's saying, it's wrong. Pick the thing a person would picture (₹1000 a month → a calendar with a deposit dropping into every month), not abstract shapes.
- The visual never just prints the caption ("₹1000 a month" text over the graphic = repeat).
- Every visual stays on screen long enough to be understood; transform one object into the next instead of cutting it away early.
- Same logic picks b-roll: what does this line make the viewer feel or picture? Show that, better than words can.

## Video structure + b-roll brain (his rules 2026-11-12, video-25 notes)
**Structure:** every video opens on a **split-screen hook**: complementary b-roll on top (makes them *feel* the line), the host (or avatar) below, and a **kinetic text hook** on the split line (small words + one huge accent word, built word by word; strike-through allowed). After the hook, the video mixes: host split screen, host full screen, **b-roll** beats and **infographic** beats, to maximise understanding.

**B-roll brain, per line:**
1. What should the viewer feel or picture on this line? (three channels: the clip shows it better than words)
2. Source order: **movie / sitcom scene** that IS this moment (Indian audience → Bollywood first: 3 Idiots, Chhichhore, Taare Zameen Par, Do Dooni Chaar, ZNMD, Wake Up Sid…) → real-life footage → photo → motion graphic → word.
3. Recognisable in ~0.5 s; match the emotion of the beat, not a quote. Emotional beats (first car, convocation, farewell) want emotional scenes.
4. One film once per reel (no repeats unless a callback). Clip = the line's length (1–3 s), cut on the phrase.
5. Nothing on b-roll but the caption (b-roll home, top ≈ 1070).
6. **Don't download clips.** Put a placeholder with: film, scene, what must be visible, crop, duration. He downloads and drops them in.

**Infographics:** real images (Pinterest, or ChatGPT image gen) + motion together; a chart with numbers when amounts are compared (his note: "chart type things with number so viewer can compare"). When a chart shows a number, the caption chunk with the same number drops. A hold over ~1.5 s needs new motion (his note: boring at 8 s).
